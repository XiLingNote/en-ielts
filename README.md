# 雅思核心词汇 2683 循环朗读伴读助手 (en-ielts)

专为雅思备考与日常英语单词听背打造的轻量级、零依赖单文件 Web 伴读工具。完美适配 PC 与手机移动端触控，支持纯英文浸入与中英双语循环朗读。

---

## 🌟 核心特色

1. **预置雅思核心 2,596 词库**：
   - 提取自新东方雅思基础核心词库（真实去重 2,596 词）；
   - 每个单词均附带 **100% 纯正美式音标（US）** 与详细词性/中文释义；
   - 支持通过【导入词库】随时扩充或自定义任何 3000/5000 词库。
2. **纯前端离线运行，零服务器依赖**：
   - 基于浏览器原生 Web Speech API；
   - 毫秒级响应，即使完全断网或无网络环境下也能顺畅朗读。
3. **双语模式自由切换**：
   - **纯英模式**：沉浸式听读，适合快速过词、拼写记忆与磨耳朵；
   - **双语伴读**：英文发音 ➔ 自动朗读中文含义 ➔ 设定间隔停顿，适合通勤、散步、闭目养神时不用看屏幕听背。
4. **全端深度适配**：
   - **PC 端**：大屏极简卡片、目录即时跳转、全键盘快捷键（<kbd>Space</kbd> 播放/暂停，<kbd>←</kbd> / <kbd>→</kbd> 切换，<kbd>R</kbd> 重读）；
   - **手机移动端**：自适应单手大触控按键、防误触、防移动端 Safari 垃圾回收断音。
5. **断点记忆续听**：
   - 学习进度实时保存于本地 `localStorage`，刷新或下次打开依然停留在当前单词。

## 🚀 GitHub Pages 部署指南

本项目为纯静态单文件应用，可在 GitHub 一键开启免费公网访问：

1. 访问本仓库页面：`https://github.com/XiLingNote/en-ielts`
2. 点击仓库顶部的 **Settings（设置）**；
3. 在左侧边栏找到 **Pages**；
4. 在 **Build and deployment** 下方的 **Branch** 选择：
   - 分支：`main`
   - 目录：`/ (root)`
5. 点击 **Save** 保存；
6. 约 1~2 分钟后刷新页面，即可获得专属线上网址（例如：`https://xilingnote.github.io/en-ielts/`），手机浏览器打开即可随时随地背单词，支持【添加到主屏幕】作为 PWA 全屏 App 使用。

## 💻 本地运行

- **电脑端**：直接双击 `index.html`，使用 Edge 或 Chrome 打开即可。
- **手机同 Wi-Fi 访问**：双击运行 `start_mobile.bat`，手机浏览器输入终端提示的局域网 IP 即可无线使用。
